Full-Stack Application

How this works:

This HTML frontend (running in your browser) is connected to a Python/Flask backend (running on your server).

When you click a "Start" button, this page will send an API request to the Flask server, which will then run the actual Selenium and PyMuPDF code.

IMPORTANT: The crawling process (Stage 1) can take several minutes. Do not close this browser tab while it is running.
